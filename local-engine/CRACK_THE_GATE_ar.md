# تحديث صقر V143 — المحرك 2.3.3

هذه حزمة تحديث للنسخة الحالية، وليست مشروعًا كاملًا. الواجهة تعتمد على ملفات CSS وJavaScript الموجودة في مشروع صقر الأصلي؛ انسخ الملفات فوق نظيراتها ولا تحذف بقية المشروع.

## التغييرات
- دعم Crack the Gate: قراءة تعليقات HTML وفك ROT13 واكتشاف ترويسة المطور ومسار الدخول.
- دعم حقول JSON المختصرة مثل `{email,password}`.
- عدم إعلان نجاح من علم ورد في استجابة HTTP فاشلة أو مع `success:false`.
- تسجيل مصدر العلم من استجابة التحويل الفعلية.
- إزالة النص الحرفي الزائد `\n` من الصفحة وتحديث كسر التخزين المؤقت إلى V143.
- إبقاء قفل الأصل وعدم اختيار Old Sessions لصفحة غير مطابقة.

## التركيب
1. أوقف المحرك المحلي.
2. انسخ `local-engine/falcon_local.py` و`local-engine/web_session_audit.py` إلى مجلد المحرك الحالي، مثل `C:\Falcon`.
3. انسخ `index.html` و`frontend/js/web-sessions.js` فوق نظيريهما في مشروع الواجهة.
4. أعد تشغيل المحرك وتحقق من `http://127.0.0.1:8765/health`: الإصدار 2.3.3.
5. حدّث صفحة صقر باستخدام Ctrl+F5.

## التحقق الفعلي
نجح 44 فحصًا في `tests/test_crack_the_gate.py`، ونجح اختبار HTTP في `tests/test_crack_the_gate_http.py` باستخدام محاكاة محلية. لم يُختبر رابط تحدٍ حي، ولم يُستخرج علم حي خلال هذا التحديث.

بعد دمج التحديث في المستودع الكامل نجح أيضًا اختبار Old Sessions (18 فحصًا) واختبار HTTP الأصلي.

تشغيل الاختبارات المتاحة:
```
python tests/test_crack_the_gate.py
python tests/test_crack_the_gate_http.py
```

إصلاح إضافي: دعم المسافة قبل قوس fetch، وخيارات طويلة، وJSON.stringify(data) مع تعريف حقول data قبل الطلب.

الواجهة ترسل نص التحدي للمحرك المحلي. يؤخذ البريد الصريح أولًا ثم البريد الوحيد في النص ثم الصفحة. غياب البريد أو تعدده يوقف طلب الدخول ويطلب إدخاله؛ لا يوجد بريد افتراضي ثابت.
