# صقر V147 — دعم تحدي n0s4n1ty 1

يكتشف المحرك نموذج POST متعدد الأجزاء واسم حقل الملف من HTML الحي. يرفع `falcon_cmd.php` بحقل الملف المكتشف، ثم لا يتابع إلا إذا أكدت الاستجابة مسارًا داخل `uploads/`. بعد ذلك يتحقق من تنفيذ PHP بـ `whoami`، ويقرأ `sudo -l`، ولا يطلب `/root/flag.txt` إلا إذا أثبتت الاستجابة وجود تصريح `NOPASSWD`.

عند رفض الرفع، يعرض رمز HTTP ومقتطف رد الخادم، ويتوقف قبل تنفيذ أي أمر. يتعرف كذلك إلى صفحة Kaspersky Endpoint Security ذات HTTP 499 كاعتراض محلي، ويفصلها عن رد تطبيق التحدي؛ لا يقترح تغيير الحمولة أو تجاوز الحماية. لا يدّعي استخراج العلم إلا إذا ظهر نمط علم في رد HTTP الفعلي.

الاختبار المحلي: `python tests/test_n0s4n1ty.py` يغطي اكتشاف الحقل، الرفع الناجح، استخراج علم وهمي، رفض التطبيق، اعتراض Kaspersky، والتوقف عند غياب تصريح sudo.
