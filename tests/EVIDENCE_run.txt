[1] GET /  =>  302 Found  ->  /login
    Set-Cookie: session  [set]
      - Expires في المستقبل (~31.3 سنة): كوكي دائمة على المتصفح.
      - تنبيه: تاريخ الانتهاء البعيد وحده لا يثبت أن جلسة المصادقة لا تنتهي على الخادم؛ يجب التحقق من سلوك الخادم.
    • طلب الصفحة الرئيسية دون جلسة: نتوقع تحويلًا إلى /login وإنشاء كوكي جلسة.
    • خُزّنت/حُدّثت الكوكي «session».

[2] GET /login  =>  200 OK
    Set-Cookie: session  [deletion]
      - Max-Age <= 0: هذا طلب حذف للكوكي (وليست دائمة).
      - القيمة فارغة مع نية الحذف: إزالة واضحة للكوكي.
    • صفحة /login: نتوقع 200 مع طلب حذف كوكي الجلسة (Max-Age=0).
    • حُذفت الكوكي «session» بناءً على طلب الخادم (Max-Age<=0 أو Expires ماضٍ).

[3] GET /register  =>  200 OK
    • صفحة /register: الحقول المكتشفة = ['username', 'password', 'conf_password'].

[4] POST /register  =>  400 Bad Request
    • إثبات المتطلب: إرسال username+password فقط (بدون conf_password) — نتوقع 400.

[5] POST /register  =>  302 Found  ->  /login
    • تسجيل صحيح مع conf_password: نتوقع 302 إلى /login.

[6] POST /login  =>  302 Found  ->  /
    Set-Cookie: session  [set]
      - Expires في المستقبل (~31.3 سنة): كوكي دائمة على المتصفح.
      - تنبيه: تاريخ الانتهاء البعيد وحده لا يثبت أن جلسة المصادقة لا تنتهي على الخادم؛ يجب التحقق من سلوك الخادم.
    • تسجيل الدخول: نتوقع 302 إلى / وكوكي جلسة طويلة.
    • خُزّنت/حُدّثت الكوكي «session».

[7] GET /  =>  200 OK
    • الصفحة الرئيسية بعد الدخول: التلميح المكتشف = /sessions.

[8] GET /sessions  =>  200 OK
    • صفحة /sessions: نتوقع تسريب قائمة جلسات الخادم.

[9] GET /  =>  200 OK
    • انتحال جلسة المشرف: ضبط كوكي session على رمز المشرف ثم طلب /.

الشرح:
  1) الصفحة الرئيسية تُنشئ كوكي جلسة (غالبًا بتاريخ انتهاء بعيد) ثم تُحوّل إلى /login.
  2) صفحة /login تحذف كوكي الجلسة (Max-Age=0). لهذا لا نتبع التحويلات تلقائيًا: الحذف دليل يظهر فقط في الاستجابة الوسيطة.
  3) أنشأنا حسابًا تجريبيًا (conf_password مطلوب، وإلا 400).
  4) سجّلنا الدخول وحصلنا على كوكي جلسة طويلة الصلاحية للحساب التجريبي.
  5) الصفحة الرئيسية تكشف تلميحًا لصفحة مخفية: /sessions.
  6) صفحة /sessions تسرّب جلسات الخادم (عدد الإدخالات: 3)، ومنها جلسة المشرف.
  7) استبدلنا كوكي جلستنا برمز جلسة المشرف المسرّب، فأصبحنا مشرفين.
  8) استُخرج العلم من step9:GET /.
